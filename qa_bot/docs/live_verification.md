## Незакрытые ограничения

- Нужен рабочий способ входа в свежую сессию (новая действующая ссылка либо
  личный интерактивный вход), затем отдельный подтверждённый DOM/layout-профиль.
- Требуется личное решение пользователя на странице уведомления. Наличие
  assessment-токена не превращает его в staging media API.
- Unknown synthetic LLM engine проверен на mocks; реальный Codex вызов не выполнен.
- General-purpose OCR, разрешённый реальный audio source, полная recovery-оркестрация
  и реальный execution adapter не готовы. Production executor намеренно закрыт.
- 1251 исходных записей доступны как candidate; утверждённых ответов нет.

Пакет передаётся как development preview с этими ограничениями, не как готовый
автономный тестовый клиент.
