# Полная локальная копия для проверки

Снимок проекта `SHL-question-bank` от 7 сентября 2026 года, исходный коммит
`d58fdae5bf0e4cdad6d0086018cd5f8509e24381`.

Архив содержит исходники и локальные файлы, включая игнорируемые Git зависимости,
модели, данные, аудио, отчёты, кэши и локальную конфигурацию. Поскольку репозиторий
публичный, полная копия зашифрована AES-256-GCM. Двоичный ключ хранится отдельно
у владельца и не включён в репозиторий. Для проверки содержимого нужен этот ключ.
Обычные исходники также доступны в основной структуре этой ветки.

Исключены только служебный `.git` (метаданные связанного рабочего дерева) и эта
папка снимка, чтобы архив не включал сам себя. Сохраняются содержимое файлов,
права доступа, время изменения, каталоги, символические ссылки и именованные
каналы FIFO. ACL, расширенные атрибуты macOS и время создания не переносятся.
Это снимок файлов проекта, а не образ всей системы или работающих процессов.

## Восстановление

Нужны Node.js 18+ и Python 3.9+ на macOS/Linux. Скачайте все части архива и файлы
в этой папке. Ключ передавайте отдельно, не добавляя его в Git.

```sh
node restore.mjs --key-file /absolute/path/snapshot.key --output /absolute/path/restored-project
```

Команду запускайте из этой папки. Папка назначения должна отсутствовать или быть
пустой. Восстановление проверяет SHA-256 каждой части, подлинность всего архива,
а затем SHA-256 каждого восстановленного обычного файла, права и цели ссылок.
При неверном ключе или повреждении шифротекста извлечение не начинается.
Расшифрованный временный архив удаляется после завершения команды.

Полный список файлов и их контрольные суммы находятся внутри зашифрованного
архива (`__snapshot_manifest__.json`). Открытый `snapshot.json` содержит только
сводные сведения, параметры шифрования и контрольные суммы частей.

В снимке сохранены зависимости macOS/Apple Silicon и исходные ссылки Python на
локальную среду владельца. Для запуска на другом компьютере может понадобиться
пересоздать `.venv` и настроить внешние сервисы. Наличие полного снимка само по
себе не означает успешного прохождения всех внешних тестов; результаты и текущие
ограничения описаны в `qa_bot/LIVE_QA.md` и локальных отчётах внутри архива.
